Privacy Policy — LMNOP

Last updated: October 2026

LMNOP ("the app") is a free, personal electrolyte-recipe calculator available at benhumphrey.github.io/lmnop. This page explains what data the app touches and how.

What data the app stores

LMNOP stores the following directly in your browser's local storage, on your own device:

  • Your saved electrolyte recipes and serving preferences
  • If you choose to enable sync: a GitHub personal access token you provide, and the ID of a GitHub Gist used to store your recipes

None of this data is ever sent to any server operated by the app's author. There is no backend, no database, and no analytics or tracking of any kind.

Optional GitHub sync

If you choose to enter a GitHub personal access token, the app uses it only to read and write a single Gist (a small file hosted on GitHub's own servers) so your recipes can sync across your devices. That token and the Gist ID are stored only in your browser's local storage — never transmitted anywhere except directly to GitHub's API over HTTPS, and never seen by the app's author. You can clear this token at any time from within the app, and you can revoke it directly from your GitHub account settings.

If you skip this step, the app works entirely offline using only your browser's local storage, and no data leaves your device at all.

Cookies and tracking

LMNOP does not use cookies, analytics, or any third-party tracking scripts.

Data sharing

No data collected or stored by this app is sold, shared, or disclosed to any third party.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a revised "Last updated" date.

Contact
